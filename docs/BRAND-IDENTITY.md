# Brand identity — WindVeal Biz Platform

## Identity

- Company: WindVeal
- Product: WindVeal Biz Platform
- Product identity: typography-led; no logo or symbol.
- Workspace names: Recruitment, People & HR, CRM, Workflows, Documents and Insights.

## Typography

Use **Manrope** as the initial display/wordmark typeface for the product name. Use a legible UI family such as **Inter** for interface text, tables, forms and data. The product name should be visually distinctive through weight, spacing and typographic hierarchy, not through an added icon.

Before release, verify font licences and package the required font files for offline use. Avoid relying on a remote font request for the installed desktop application.

## Colour tokens

Initial values sampled from the supplied WindVeal blue reference:

| Token | Value | Use |
| --- | --- | --- |
| Primary blue | `#486FE4` | Primary actions and key interactive states |
| Deep blue | `#263F91` | Strong emphasis and selected states |
| Navy | `#172B63` | Dark text accents and premium contrast |
| Pale blue | `#EEF3FF` | Soft backgrounds and selected surfaces |
| White | `#FFFFFF` | Main light surfaces |

Use neutral greys for body text, borders and secondary surfaces. Check WCAG contrast for every text/action pairing. Add semantic success, warning and danger colours only as functional status colours, not as competing brand colours.

## Usage rules

- Do not use the uploaded symbol as a logo.
- Do not create a replacement icon, monogram or emblem.
- Do not split workspaces into separate brands.
- Always write the product name as **WindVeal Biz Platform** in formal product copy.
- Use the functional workspace names exactly as listed above.
- Support light and dark themes while preserving the blue brand identity and readable contrast.
